# 🎯 交易决策分析系统 - 最终版

## 系统概述

基于您的要求重新设计的精细化数据聚合和AI交易决策系统，专门用于做多/做空/持有决策分析。

## 🔧 核心改进

### 1. 精细化深度数据聚合
- **10美元精度**: 将depth_snapshot_5000的bids和asks按照10美元精度向下取整聚合
- **价格档位**: 每个价格层级都是10美元间隔，包含聚合后的挂单量
- **深度统计**: 计算买卖双方集中度和流动性分布

### 2. 多周期交易数据
- **短周期**: 最近30分钟的1分钟详细数据
- **长周期**: 4小时聚合数据（最高价、最低价、成交量、delta、总成交量）
- **决策导向**: 数据格式专为做多/做空/持有决策优化

### 3. AI交易决策分析
- **分析目标**: 当前应该做多、做空还是持有
- **专业提示词**: 针对交易方向决策的英文提示词
- **风险管理**: 包含完整的止损止盈和仓位建议

## 🤖 AI分析输出格式

### JSON标准输出

AI会返回标准JSON格式的分析结果：

```json
{
  "direction": "Buy",
  "lower_bound": 114650.0,
  "upper_bound": 115800.0
}
```

### 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `direction` | string | 交易方向 | "Buy", "Sell", "Hold" |
| `lower_bound` | number | 交易区间下界 | 114650.0 |
| `upper_bound` | number | 交易区间上界 | 115800.0 |

### 决策摘要显示

```
📋 决策摘要
============================
🎯 推荐操作: 📈 做多
📊 交易区间: $114,650.00 - $115,800.00
📏 区间宽度: $1,150.00
🌐 中文方向: 做多
✅ 数据格式: JSON (有效)

💡 建议在区间下限 $114,650.00 附近入场
🎯 目标价位区间上限 $115,800.00
```

### 交易方向解释

| Direction | 含义 | 入场建议 | 目标建议 |
|-----------|------|----------|----------|
| **Buy** | 做多 | 在lower_bound附近入场 | 目标upper_bound |
| **Sell** | 做空 | 在upper_bound附近入场 | 目标lower_bound |
| **Hold** | 持有 | 在区间内观察 | 突破区间再入场 |

### AI决策分析

系统会基于以下维度进行综合分析：

1. **深度订单簿分析**
   - 流动性分布
   - 支撑阻力强度
   - 订单流不平衡

2. **短期动量分析**
   - 30分钟价格方向
   - 成交量模式
   - 买卖压力

3. **中长期趋势**
   - 4小时趋势分析
   - 成交量积累分布
   - 趋势持续性评估

4. **风险评估**
   - 支撑阻力邻近度
   - 成交量确认
   - 时间框架对齐

### 配置文件
确保 `config/development.yaml` 包含：
```yaml
redis:
  host: "localhost"
  port: 6379
  decode_responses: true

analyzer:
  deepseek:
    enable: true
    api_key: "your_deepseek_api_key"
    base_url: "https://api.deepseek.com/v1"
    model: "deepseek-chat"
    max_tokens: 6000
    temperature: 0.1
```

## 📄 输出文件

运行后自动生成：

1. **`trading_analysis_data_YYYYMMDD_HHMMSS.txt`**

   - AI可直接读取的文本格式

2. **`trading_decision_prompt_YYYYMMDD_HHMMSS.txt`**
